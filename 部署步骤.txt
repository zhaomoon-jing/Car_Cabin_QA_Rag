1.将项目放置 /opt/car_rag
2.创建虚拟环境并安装依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

配置 systemd 开机自启
cp deploy/car-rag.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable car-rag.service
systemctl start car-rag.service

接口测试
导入deploy/CarRAG.postman_collection.json至 Postman 进行调试
注意事项
车机局域网访问，将地址127.0.0.1修改为设备 IP
llama.cpp GGUF 模型提前放置指定路径，修改代码内模型路径
低配车机可调整 CPUQuota、MemoryMax 资源限制
推理采用单进程，禁止多进程启动模型，避免内存翻倍
